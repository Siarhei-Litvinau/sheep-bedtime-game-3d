# ПРОМТ: скачать и подключить аудио к проекту "Овцы перед сном"

Вставь этот файл в Claude Code (в папке проекта) и попроси: "Прочитай audio-download-prompt.md и выполни все шаги — скачай файлы и подключи их к игре по таблице событий".

---

## Важно: что можно скачать автоматически, а что нет

- **Freesound (превью-файлы) и Kenney.nl** — дают прямые ссылки на файлы без авторизации, Claude Code может скачать их сам через `curl`/`wget`.
- **Pixabay** (фоновая музыка, часть эффектов) — сайт отдаёт файлы только через JS-интерфейс без авторизации по API-ключу, прямых стабильных ссылок для автоматического скачивания нет. Эти файлы нужно будет скачать вручную через браузер и просто положить в указанную папку — дай Claude Code инструкцию ниже, он подскажет, куда именно класть файл, когда до этого дойдёт очередь.

Если в вашей среде Claude Code сетевой доступ ограничен (нет доступа к нужным доменам) — он сообщит об этом; в таком случае просто скачайте файлы по ссылкам сами и положите в папку `assets/audio/` вручную, взяв имена файлов из таблицы ниже.

---

## 1. Инструкция для Claude Code

> Создай папку `assets/audio/` в корне проекта (если её ещё нет). Скачай следующие файлы по прямым ссылкам через curl, сохраняя указанные имена. После скачивания подключи каждый файл к соответствующему игровому событию согласно таблице в разделе 3 — найди в коде места, где сейчас происходят эти события (тап на овцу, отпускание/прыжок, приземление, вход в амбар, тап на NPC, старт/окончание сессии), и добавь воспроизведение звука через Web Audio API или `<audio>`/Howler.js, в зависимости от того, что уже используется в проекте. Громкость всех эффектов сделай изначально умеренной (не более 60% от максимума) и подключи её к общей "угасающей" кривой отклика, уже описанной в основном промте игры (звук тише к финалу сессии). Для фонового трека — зацикли воспроизведение и подключи громкость к общей световой/цветовой кривой сессии (плавное затухание к финалу).

## 2. Прямые ссылки для автоматического скачивания

```bash
mkdir -p assets/audio

# Уханье совы (CC0, Freesound, автор Breviceps)
curl -L "https://cdn.freesound.org/previews/465/465697_9159316-lq.mp3" -o assets/audio/owl_hoot.mp3

# Мурчание кота (CC0, Freesound, автор cubilon)
curl -L "https://cdn.freesound.org/previews/130/130968_2330675-lq.mp3" -o assets/audio/cat_purr.mp3

# UI-звуки (CC0, Kenney.nl, Interface Sounds pack — 100 звуков в архиве)
curl -L "https://kenney.nl/media/pages/assets/interface-sounds/fa43c1dd4d-1677589452/kenney_interface-sounds.zip" -o assets/audio/kenney_interface_sounds.zip
cd assets/audio && unzip -o kenney_interface_sounds.zip -d kenney_ui_sounds && cd -
```

**После распаковки Kenney-пака**: попроси Claude Code прослушать/проверить содержимое папки `kenney_ui_sounds` и выбрать 2–3 самых мягких, негромких клика (обычно файлы вида `click_soft.ogg`, `switch_ambient.ogg` в паке имеют подходящий не резкий звук) — переименовать выбранные в `tap_soft.mp3`/`tap_gentle.mp3` для использования в разделе 3.

## 3. Таблица событий → звуковые файлы

| Игровое событие | Файл | Источник | Примечание |
|---|---|---|---|
| Тап/удержание овцы (начало разбега) | `tap_soft.mp3` (из Kenney-пака) | Kenney | самый тихий доступный клик |
| Отпускание / прыжок | `tap_soft.mp3` + лёгкий pitch-shift выше | Kenney | можно слегка повысить тон программно для разнообразия |
| Приземление овцы | `sheep_bleat.mp3` (скачать вручную, см. раздел 4) | Pixabay | короткое блеяние |
| Овца скрывается в амбаре / окно загорается | `tap_soft.mp3` тише и мягче (низкая громкость) | Kenney | переиспользовать с приглушённой громкостью |
| Тап по сове | `owl_hoot.mp3` | Freesound (автоскачано) | — |
| Тап по коту (сворачивание) | `cat_purr.mp3` | Freesound (автоскачано) | зациклить на 2–3 сек после срабатывания |
| Тап по облаку (зевок) | `tap_soft.mp3` | Kenney | либо отдельный мягкий "вздох"-звук, если найдётся в паке |
| Фоновая музыка (весь сеанс) | `background_ambient.mp3` (скачать вручную, см. раздел 4) | Pixabay | темп 60–80 BPM, замедление к финалу — реализуется программно, не сменой файла |
| Завершение сессии / затемнение | тишина + затухание фоновой музыки | — | без отдельного файла, просто fade-out по громкости |

## 4. Файлы для скачивания вручную (Pixabay)

Эти два зайдите скачать через браузер самостоятельно — прямых ссылок для скрипта нет:

1. **Блеяние овцы** — откройте https://pixabay.com/sound-effects/search/sheeps/, прослушайте варианты, скачайте короткий (1–3 сек) файл, положите в `assets/audio/sheep_bleat.mp3`.
2. **Фоновый эмбиент-трек** — ✅ готово: `leberch-sleep-music-587996.mp3` (Pixabay, автор Leberch), лежит в `assets/audio/`, транскодирован в `public/audio/background_ambient.mp3` (128 kbps — исходник был 256 kbps/28.6MB, для веба это лишнее).

После того как оба файла лежат в папке — просто напишите Claude Code: "файлы sheep_bleat.mp3 и background_ambient.mp3 добавлены в assets/audio/, подключи их по таблице раздела 3".

## 5. Лицензии — что учитывать при публикации

- **CC0** (Freesound-файлы owl_hoot/cat_purr, весь Kenney.nl) — можно использовать без каких-либо условий, атрибуция не нужна.
- **Pixabay Content License** — коммерческое использование разрешено без указания авторства, но нельзя перепродавать сами аудиофайлы как самостоятельный продукт — для использования внутри игры это не проблема. Фоновый трек `background_ambient.mp3` — «Sleep Music», автор **Leberch** (Pixabay, ID 587996); атрибуция не обязательна по лицензии, указана здесь для истории/на случай проверки условий перед публикацией. Стоит один раз проверить актуальные условия на самом Pixabay перед публикацией игры.
